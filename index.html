À propos de Stellio

STELLIO

VChargement...

Stellio est un gestionnaire de fichiers 3D moderne et léger, conçu pour les makers, imprimeurs 3D et passionnés de modélisation. Il centralise vos fichiers STL, 3MF et OBJ, génère des miniatures haute qualité via PyVista et s'intègre directement avec votre Slicer.

Ajouter une imprimante

Tapez la marque et le modèle pour vérifier la compatibilité
Fonctionne avec n'importe quelle imprimante connectée à un OctoPrint (Raspberry Pi ou équivalent) : Artillery Sidewinder/Genius, Prusa MK3/MK2.5, Snapmaker Artisan (via le plugin OctoPrint dédié), la plupart des imprimantes Marlin classiques, et certains modèles FlashForge/Dremel via un plugin OctoPrint dédié.
Fonctionne avec tout ce qui expose Moonraker : Creality K2/K2 Pro/K2 Plus/K2 SE, Qidi Q1 Pro/X-Max, FLSUN V400/S1/Q5/Super Racer/T1 et Snapmaker U1 (Moonraker intégré d'origine sur tous ceux-là), Voron et tout Klipper DIY. Le Creality K1/K1C/K1 Max et l'Anycubic Kobra 3/S1/Kobra 2 Pro nécessitent d'abord d'installer un firmware communautaire (Helper Script de Guilouz pour Creality, Rinkhals pour Anycubic) — leur firmware d'origine n'expose pas Moonraker.
Sur l'imprimante : Réglages → Réseau → PrusaLink. Le nom d'utilisateur est toujours maker — utilisez le mot de passe/clé API affiché à cet écran dans le champ ci-dessous.
Sur certains modèles P1P / P1S / A1 (selon la version du firmware), activer l'accès local MQTT peut nécessiter le "LAN Only Mode" sur l'imprimante — ce qui désactive le cloud Bambu (Bambu Handy, monitoring à distance, MakerWorld). Les X1/X1C ne sont généralement pas concernés. Vérifiez sur votre imprimante avant d'activer ce mode si vous tenez au cloud.
Détermine le protocole utilisé pour le flux caméra (port 6000 pour A1/P1, RTSPS port 322 pour X1/X2/H2)
Trouvé dans l'interface Bambu Lab → Réseau → Code d'accès
Améliore le monitoring MQTT (Paramètres → Général sur l'imprimante)
Pas de code d'accès nécessaire — Stellio détecte automatiquement l'imprimante sur le réseau à partir de son IP (protocole SDCP, sans authentification).
Le code d'accès local par défaut est 123456 tant qu'il n'a pas été changé sur l'imprimante (Réglages → Réseau).
Pas de code d'accès nécessaire — assurez-vous que le mode LAN est activé sur l'imprimante (Réglages → Réseau).
Le numéro de série et le code de vérification sont affichés dans l'écran de l'imprimante, sous Réseau → LAN.
